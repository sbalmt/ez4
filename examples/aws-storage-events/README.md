# AWS S3: Events

This example showcases S3 object event handlers with typed trigger selection.

## Getting started

Create a `local.env` following `example.env` and fill it with AWS credentials.

#### Install

```sh
npm install
```

#### Deploy

```sh
npm run deploy
```

> This action creates resources on the given AWS account.

#### Destroy

```sh
npm run destroy
```

> This action deletes the resources created by this example.
